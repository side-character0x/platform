## NEXUS

- NEXUS is a platform that allows you to have conversations with another user and agents (simple bots) and can command the agents to perform basic tasks like pining and unpinning any mesages, adding and removing tasks.(currently in the development phase)

## Features

- has a bot the greets the user when they make their very first message.
- has a bot that can pin and unpin messages.
- has a bot that can add and remove tasks.
- has channels where one user can chat with another user and agents (simple bots).

## Technologies Used

- Groq
- Flask
- Python
- HTML/CSS

## Why I built this

- I wanted to build a app where I can use bots to do things for me and also have a conversation. (currently in the development phase until now, but I will try to implement more features in the future.)

## Limitations

- No real time messaging.
- Has very less features currently.
- Need to refresh the page for getting the latest messages.
- Requires Internet connection.
- Can't run 2 accounts in same browser cookies.

## Test

- Available at "tests" inside the same repository.

## How to run (The .exe Version)
1. Download the `.zip` file through demo link and extract it.
2. Open the extracted folder. **Do not move the `.exe` out of this folder** (it needs the `_internal` folder to run).
3. Double-click `.exe` file. A black console window will open.
4. Browser will automatically open.
